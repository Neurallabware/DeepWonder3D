# Validation and limitations

Check each stage on a small known recording before a large run. For 3D results, check calibration transfer, view correspondence, localization coordinates/units, neuron merging, and trace timing.

Use `main_pipeline_2d.py` when axial localization is not required. Changing the selected modules requires checking that prerequisite outputs exist.

This documentation change validates the guide and build configuration. It does not establish a reproduced performance claim, model inference result, or correct optical calibration.
